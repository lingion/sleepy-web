## 明确例外与共享职责

- Web 的 `AlertDialog` 默认 `glassRole="alert"`，其 TextButton 默认 regular。备份导入确认外壳与文字动作显式传 false。AllTables 复制对话框只有外壳 false，内部使用与原生相同的 DialogActionButtons。
- Import、AddCourse、EditTable 的局部 Overlay 同样提供默认 alert 和显式 false；CourseSelection 使用 false。不能按 `role="dialog"` 扫描增强所有窗口。
- Web 独有的 ICS 导出选项面板在固定 Android HEAD 中没有相同面板调用，保持普通载体；其明确的取消与导出动作分别 regular 和 primary tinted。Widget 的 Web 能力提示是显式 AlertDialog，不把 gallery 卡片变成玻璃。
- SettingsScaffold 提供 glassNavigation 开关。BackupOnly 显式传 false，遵循 BackupScreen 普通 Material IconButton 的例外；其他调用按各自原生顶栏声明。
- 语言菜单删除局部的临时 blur/border 玻璃 CSS，交由显式 menu 角色的统一样式处理；选中行保持普通背景与对勾。
- ColorPickerDialog 使用 slider 透镜、hue/360 位置及当前 hue 的显式 thumb 颜色。几何与其他精细滑杆一致，经典模式仍显示原有圆形 thumb。
