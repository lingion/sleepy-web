## 位置与操作顺序不变量

```text
课表整条顶栏
[切表][撤回 取消撤回]   [上一周][完整第 N 周][下一周]   [加课][分享]
                                  屏幕绝对中心
窄屏处理顺序：缩外边距和内部间距，缩侧控件，极端才共用三段周次胶囊。

课程编辑卡的折叠标题行
[标题和两行摘要，占满剩余宽度] [删除叉，48像素槽] [折叠箭头，48像素槽]
[展开内容：星期、节次、周次、教师、地点、备注、时段颜色]
编辑时只有命中来源主键的卡先展开；新加时段立即展开。

底部导航
[课表] [今日] [课表管理] [我的]
贴底通栏、悬浮胶囊和平板导航保留同一顺序。

单次操作
周视图长按：调整本次和删除本次菜单，选择调整后显示表单。
浮卡明确点击调整本次：直接显示表单。
拖动或改长度：预览，确认，调休日归属审批，冲突确认，保存。
返回修改回到浮卡；完成退出浮卡；取消不写库。
```

## 主线共享接口与整合验收

本代理没有修改data/types、repository、prefs模型、themes或reminders。单次纯模块已独立交付，主线保存接口按下列合同实现：

```ts
interface CourseOccurrence {
  course: Course
  sourceDate: string
  displayDate: string
}
withoutOccurrence(course: Course, sourceDate: string, startDate: string): Course[]
mergeMatchingRows(rows: Course[]): Course[]
coursesForDate(date: string, startDate: string, maxWeek: number,
  courses: Course[], transfers: HolidayTransferEntry[]): Course[]

saveOccurrence(occurrence: CourseOccurrence, replacement: Course | null,
  expectedCourses: Course[], expectedTable: Table,
  expectedTransfers: HolidayTransferEntry[]): Promise<boolean>

saveCourseDraft(drafts: Course[], replacingGroupId: string | null,
  expectedCourses: Course[], expectedTable: Table, draftTimeJson: string,
  expectedTransfers: HolidayTransferEntry[], replacingCourseId?: number): Promise<boolean>

setGroupSourceColor(tableId: number, groupId: string, hex: string): Promise<void>

// prefs模型、默认值、加载与备份编解码由主线接入。
uiStyle: 'classic' | 'liquid_glass'

```

`saveCourseDraft` 必须按用户看到的课程、有效绑定作息及调休快照原子校验；有变化返回false，不写库、不添加撤回。空groupId旧课用 `replacingCourseId` 精确替换，不匹配其他空组。`draftTimeJson` 包含边缘节次草稿，确认后与课程一起持久化。组色接口只改该组GROUP行，AUTO和CUSTOM保留，撤回与变更通知由repository统一处理。

本轮读取主线 `/Users/lingion_k/sleepy-worktrees/web-embed-demo-20261110` 时，saveOccurrence和uiStyle已存在；尚未找到saveCourseDraft、setGroupSourceColor与periodHeaderHideTime定义。相关翻译键已存在，主线继续处理六语文本。该现场记录只描述读取时状态，不能替代主线之后的整合结果。

本分支通过类型扩展声明调用主线接口，测试有mock；浏览器没有用缺失接口完成真实保存。因此主线仍需验收以下整合项：新建和编辑的完整保存、空groupId单行替换、组色立即保存及撤回、单次移动和删除的真实保存及撤回、共享作息变化或调休变化时拒绝陈旧审批、隐藏时间偏好重载和备份保留。App.tsx本代理不再修改，`#/今日/课程汇总/:date`及daily agenda由主线接入。PeriodTableEditView合并时保留主线主动删除作息表冻结绑定、bound_hint确认和unsaved guard。
