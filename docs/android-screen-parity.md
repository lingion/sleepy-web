## 布局不变量

选校页的列表顺序保持为推荐卡、自定义链接、字母分组和完整学校行；未来若存在真实成功导入记录，Android 的最近学校卡位于推荐卡之前。当前 Web 没有教务导入成功路径，因此不制造最近学校记录。正常搜索收起推荐与字母索引，保留结果列表内的自定义链接；无结果时显示空态，合法网址则显示 URL 行。

```text
选校页
+------------------------------------------+
| 返回    选择学校                         |
| 搜索输入                                |
| 拼音与英文简称提示                      |
| 目录 / 已支持 / 待验证       搜索匹配数  |
|+------------------------------------+---+|
|| 推荐卡：标题与提示       定位      | A ||
|| 自定义教务链接：图标与两行文字     | B ||
|| A 分组                            | C ||
|| 学校：图标、名称、协议和网址       | . ||
|| B 分组及后续全部学校              | . ||
|+------------------------------------+---+|
+------------------------------------------+
```

“我的”页面按以下顺序构成独立列表项。页面内边距16，标题与副标题间距4，其余相邻列表项间距16。统计卡纵向18、横向8，统计格纵向4、横向12；统计分隔线高36。设置卡圆角16，设置行内边距纵向14、横向16，40像素图标容器内放20像素图标，文字左侧间距16，行的基本高度68。设置分隔线从卡片起点内缩72，使用 outline 的百分之三十透明度。底部保留16加调用方传入的导航避让高度。

```text
我的
管理你的课表与设置
[ 课表数 | 课程数 | 作息表数 ]
课表管理
[ 所有课表 / 作息表 / 节假日与调休 ]
应用设置
[ 提醒 / 外观与主题 / 通用 / 小组件 ]
数据
[ 备份与恢复 ]
[ 关于 ]
```

学校行、自定义链接、URL行、字母索引按钮、统计格和设置整行均带 `data-glass-plain`，避免被共享玻璃适配器改成浮起的普通按钮。顶栏返回按钮使用主线程提供的 `m3-icon-button`，定位与对话框动作使用 `m3-button-text`。没有修改共享 Material 原语、全局 CSS、glass 或网格。
