- HTML 并行发现数据库、数据准备与渲染入口；数据库入口不依赖 React 和翻译，提前打开 IndexedDB 和读偏好。生产构建生成带源码与产物摘要的 startup-manifest.json。

- 默认课表、绑定作息、课程和样例状态由同一只读事务返回。真实订阅的首次等值结果复用当前视图引用，避免三周几何重算；修改、删除、换表及卸载后重进仍读取最新数据库。
- 网格宽度复用正确父宽度，稳定滚动引用并删除重复宽度观察器。节次列批量测量一次解析当前字体，12 行从 84 次 computedStyle 读取降至 1 次；字体切换重新解析。
- 玻璃只在液态模式安装，经典模式零 PNG、零 filter。已知尺寸沿调用链传递，每帧差分写入，静态材质共享定义，主题、禁用态和卸载正确释放。

- 保持 RGB、透明度和六路采样的前提下减少 SVG 图重复依赖；只有采样区域被证明不透明时启用不透明优化路径。
- 解析弹簧按实际经过时间推进，保留正常帧轨迹、弹簧参数、二维回弹和果冻伸缩。
- 根路径产物使用相对资源路径，可完整挂载官网 /preview/，GitHub Pages 子路径仍沿用原配置。
