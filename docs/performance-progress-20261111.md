## 已实现

- 首屏直接加载完整课表，其他导航、设置、导入、导出、编辑和课程操作按需加载，保留原有功能。页面与对应翻译一起准备，深链加载实际目标页面并恢复完整返回链；加载失败可重试或返回。
- 公开只读课表忽略私人设置与课程汇总深链，首次页面与规范化后的课表地址一致。新增回归先复现汇总深链缺失课表按钮，再验证修复。
- 六种语言按需读取，简中拆分首屏与其他页面词条；测试逐项比较合并结果，防止丢词。切回简中仍正常加载页面翻译。
- HTML 并行发现数据库、数据准备与渲染入口；数据库入口不依赖 React 和翻译，提前打开 IndexedDB 和读偏好。生产构建生成带源码与产物摘要的 startup-manifest.json。
- 首帧等待语言、样例或公开课表、偏好及完整课表事务快照准备完成，flushSync 提交完整页面。没有增加顶层 await、load 等待器或加载遮罩。
- 默认课表、绑定作息、课程和样例状态由同一只读事务返回。真实订阅的首次等值结果复用当前视图引用，避免三周几何重算；修改、删除、换表及卸载后重进仍读取最新数据库。
- 网格宽度复用正确父宽度，稳定滚动引用并删除重复宽度观察器。节次列批量测量一次解析当前字体，12 行从 84 次 computedStyle 读取降至 1 次；字体切换重新解析。
- 玻璃只在液态模式安装，经典模式零 PNG、零 filter。已知尺寸沿调用链传递，每帧差分写入，静态材质共享定义，主题、禁用态和卸载正确释放。
- 地图循环复用标量采样对象，地图缓存保留 16 MiB 上限并容纳完整交互周期。PNG 使用 CPU 读回用途的 canvas，保留中性灰传输，避免颜色管理污染位移。
- 保持 RGB、透明度和六路采样的前提下减少 SVG 图重复依赖；只有采样区域被证明不透明时启用不透明优化路径。
- 解析弹簧按实际经过时间推进，保留正常帧轨迹、弹簧参数、二维回弹和果冻伸缩。
- 根路径产物使用相对资源路径，可完整挂载官网 /preview/，GitHub Pages 子路径仍沿用原配置。

## 实测边界

固定源码基线为 2e716653182995511ee16ecde40869d42a22bd21。环境为 Chrome 157、DPR 2、宿主页 1280×720、内嵌 402×874；完整官网不变，每请求延迟 40 毫秒，共享带宽 500000 字节每秒。冷源使用独立端口，不清理用户数据库。就绪标准为课表和课程节点出现后再经过两次 requestAnimationFrame；不以包大小或 DOM 单独出现替换标准。

原版三轮 app 就绪相对宿主起点分别为 4527.1、4364.1、4088.0 毫秒，中位 4364.1 毫秒。优化候选 next 一轮为 1675.6 毫秒，宿主 load 为 1354.8 毫秒，仍晚 320.8 毫秒。后续包含 v8 Tile 实验的联合候选一轮 DOM 为 1734.7 毫秒、两帧就绪为 2553.9 毫秒、宿主 load 为 1715.3 毫秒，仍未通过硬门。候选源码和机器负载不同，不能拼成最终三轮或保证生产设备倍率。

原版三轮正式按住 1500 毫秒均在松手后 15 秒未完全回落，分别只采到 7 帧，最大帧间隔为 5117、4751.4、3217 毫秒。SVG 和 canvas 优化后仍出现数百毫秒长帧。完整 Node CPU 基准保留在 src/components/glass/performance.results.json，仅证明公式和缓存开销，不证明浏览器流畅。

identity feTile 实验无可确认的帧收益，已从生产代码撤回；其证据保留在本机。没有删除背景折射、文字放大、彩虹边缘、二维拖动或功能来换取指标。
